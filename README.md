# marfa-swift-sdk

The Swift package `Marfa`: a thin layer over `MarfaCore`, the Rust engine in the monorepo `withmarfa/marfa` that every native client embeds. The core holds the working copy, the queue of writes and their verdicts, the event stream and blobs; this package gives them Swift types and `async` calls.

**Nothing is published, so nothing can depend on this package by URL yet.** Its binary target is a folder this repository does not commit; a release will ship the framework by URL and checksum.

## Using it from a checkout

```sh
scripts/core.sh   # builds the core at core.pin, copies it in, and generates the wire types
swift build
swift test        # the live tests run when MARFA_API_URL and MARFA_API_KEY name a server
```

`scripts/core.sh` needs the Rust toolchain and access to the private monorepo, which it clones into `.build/marfa`, or reads from `MARFA_MONOREPO` when that names a clean checkout already at the pin. The monorepo's build installs the cargo-swift version it names.

```swift
import Marfa

let copy = try await WorkingCopy.open(store: storeURL, server: Server(url: url, key: key))
_ = try await copy.hydrate(types: ["core.note"], tier: .feed)
let write = try await copy.items.create(Draft(type: "core.note", properties: ["title": "Hello"], tier: .feed))
let report = try await copy.queue.drain()
```

`MarfaTypes`, a second product, is the server's own wire shapes, generated from the pinned commit's `openapi.json`, for an app that reads an answer the working copy does not hold. `marfaContractVersion` is the contract they describe.

`Examples/MarfaSample` is a SwiftUI app for macOS and iOS over the package, generated by XcodeGen from its `project.yml`. Its `--scenario PHASE` launch argument runs one phase unattended (`hydrate`, `write`, `drain` or `catch-up`), prints each step and exits nonzero when a check fails. CI runs the four on macOS with the server stopped between `hydrate` and `write` and back for `drain`, which is how the sample is proven offline and back.

`AGENTS.md` has the rules in force, including how versions are numbered.
